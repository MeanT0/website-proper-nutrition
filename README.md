🥗 Proper Nutrition
Проект представляет собой веб-платформу о здоровом питании без жестких диет, предоставляющую инструменты для расчета КБЖУ и образовательный блог без обязательной регистрации пользователей.
🛠 Технический стек
Приложение построено на Python и фреймворке Django. В локальной среде используется СУБД SQLite, в продакшене — PostgreSQL. Серверная часть работает на Gunicorn, статические файлы обслуживаются через WhiteNoise. Хостинг реализован на платформе Render.com.
🎨 Архитектура и UI/UX
Интерфейс выполнен в минималистичном стиле с адаптивной версткой. Шаблоны имеют модульную структуру, обеспечивающую читаемость кода и быструю загрузку ресурсов. Акцент сделан на удобство ввода данных и отображение результатов калькуляторов.
🚀 Особенности деплоя
Сборка включает установку зависимостей pip и сбор статики (collectstatic). Запуск осуществляется через gunicorn с привязкой к переменной окружения $PORT.
